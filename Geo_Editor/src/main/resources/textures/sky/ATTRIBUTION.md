# Sky texture attribution

`nasa-deep-star-map-16k.png` is adapted from NASA Goddard Space Flight Center
Scientific Visualization Studio's Deep Star Maps 2020.
The source OpenEXR is a linear HDR, plate carree full-sky map built from
1.7 billion catalogued stars and prepared for spherical mapping. The runtime
panorama preserves the full field of view at 16384x8192. The original 32K EXR
was used only to derive this runtime panorama and is not distributed with the
project or `Build`.

- Source: https://svs.gsfc.nasa.gov/4851/
- Credit: NASA/GSFC Scientific Visualization Studio; Gaia DR2:
  ESA/Gaia/DPAC.

The remaining sky textures in this directory are original GeoEditor assets.

`nasa-lroc-moon-16k.png` is converted losslessly from the 16K color map in
NASA/GSFC Scientific Visualization Studio's CGI Moon Kit. The source mosaic was
assembled from Lunar Reconnaissance Orbiter Camera data and is mapped
spherically by the GeoEditor shader.

- Source: https://svs.gsfc.nasa.gov/4720/
- Credit: NASA's Scientific Visualization Studio; Ernie Wright (USRA);
  Noah Petro (NASA/GSFC); LRO/LROC instrument teams.
